## Главное для разработчика

К‑71 изучает эффект Холла **на образце германия в поле электромагнита**. Проект SELF требует интерактивно исследовать **поле одного или двух постоянных магнитов** виртуальным датчиком. Поэтому расчётная задача состоит из двух частей:

1. Найти вектор магнитной индукции **B** от магнитов в выбранной точке.
2. Найти компоненту **B** вдоль чувствительной оси датчика и, если заданы параметры элемента Холла, вычислить его напряжение.

Для первой версии в документации предложена дипольная модель магнитов. Это **рабочее приближение**, а не требование исходной методички; применимость модели и вопросы к руководителю указаны в отдельных файлах.

Оригинальный PDF сохранён для удобства команды. Его авторы и источник указаны в [источниках](источники.md); лицензия MIT проекта не распространяется на сторонний учебный материал.
