# Проверка расчётов и демонстрационные случаи

Эти проверки нужны до настройки графики: совпадение красивой картинки с ожиданием не гарантирует правильные численные показания датчика. Все численные примеры ниже относятся **к точечному диполю**, а не к реальному магниту конечного размера.

## Контрольные значения одного диполя

Пусть магнит расположен в начале координат, `M = (m, 0, 0)`, где `m = 0,1 А·м²`, а расстояние до контрольной точки `d = 0,05 м`. При `μ₀/(4π) ≈ 10⁻⁷ Н/А²`:

| Точка | Ожидаемое поле | Почему |
| --- | --- | --- |
| `(d, 0)` | `Bx ≈ +0,16 мТл`, `By = 0` | На оси диполя `B = 2·10⁻⁷·m/d³`. |
| `(-d, 0)` | `Bx ≈ +0,16 мТл`, `By = 0` | Осевое поле по обе стороны направлено вдоль момента. |
| `(0, d)` | `Bx ≈ −0,08 мТл`, `By = 0` | На перпендикулярной оси `B = −10⁻⁷·m/d³`. |

Здесь скалярный магнитный момент `m = 0,1 А·м²`. При удвоении расстояния каждый из ненулевых результатов уменьшается в **8 раз**.

## Два магнита

Поставить центры в `(-0,05 м, 0)` и `(+0,05 м, 0)`, оба момента `M = (m, 0, 0)` при `m = 0,1 А·м²`. В начале координат вклад каждого магнита `Bx ≈ +0,16 мТл`, сумма `Bx ≈ +0,32 мТл`. Если второй момент развернуть на 180°, в начале координат `Bx = By = 0` по симметрии.

Это проверяет **векторное сложение** и симметрию. Для карты в окрестности нуля важно отдельно проверить, что программа не рисует там направление стрелки из-за численного шума.

## Датчик и напряжение

В точке с полем `(Bx, By) = (0,16, 0) мТл`:

| Ось датчика | Показание |
| --- | --- |
| `α = 0°` | `B_s = +0,16 мТл` |
| `α = 90°` | `B_s = 0` |
| `α = 180°` | `B_s = −0,16 мТл` |

Если учебный пример задаёт `R_H = +0,01 м³/Кл`, `I = 0,020 А`, `t = 0,00417 м`, то при `B_s = +0,16 мТл` получаем `U_H ≈ +7,67 мкВ`. При смене знака `B_s` знак `U_H` меняется, а `|B|` остаётся неизменным. Эти выбранные параметры **не являются измеренными параметрами образца К‑71**.

## Проверки будущей реализации

- Поле в точке датчика вычисляется непосредственно из координат магнитов, без интерполяции по цветовой карте.
- Поворот обоих магнитов и датчика на один угол сохраняет взаимную физическую картину после соответствующего поворота координат.
- `B(r; M₁,M₂) = B(r; M₁,0) + B(r; 0,M₂)` с допустимой численной погрешностью.
- При `I = 0`, `B_s = 0` или `R_H = 0` идеальная формула даёт `U_H = 0`.
- Внутри маски корпуса приложение не выдаёт бесконечные или фиктивно «точные» значения.
- Экспортированная CSV-таблица содержит расстояние вдоль пути, координаты и поля с подписанными единицами; PNG и CSV соответствуют одной конфигурации.
