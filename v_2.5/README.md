# HallSim 2.5

Визуализация магнитного поля, виртуальный эксперимент и исследование датчика Холла.
Модель: точечные магнитные диполи и идеальный эффект Холла.

## Запуск

Python 3.11 или новее. Команды выполняются из `v_2.5`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Также доступен запуск `python -m hallsim`. После `python -m pip install .`
приложение запускается командой `hallsim`.

## Управление

- Магниты и датчик перемещаются мышью; у выбранного объекта есть ручка вращения.
  При перемещении магнитов карта обновляется в пониженном разрешении,
  после отпускания мыши — в полном. Пока следующий кадр рассчитывается,
  предыдущий остаётся на экране.
- «Задать путь A–B»: первый клик задаёт A, второй — B. Esc отменяет выбор,
  сохраняя прежний путь. Координаты можно ввести через «Координаты A–B»
  и применить одной кнопкой. «Убрать путь» отключает его.
- «Стрелки» и «Линии поля» включаются независимо. Стрелки размещаются
  равномерно на экране; их направление показывает направление поля,
  величина поля отображается тепловой картой.
- Колесо мыши меняет масштаб; средняя кнопка перемещает вид; R сбрасывает вид.
- В эксперименте установка фиксируется после начала измерений.
  «Начать заново» разблокирует её. Автоматические измерения могут заменять
  существующие результаты в совпавших точках.
- Графики можно свернуть. Таблица измерений открывается вместо графика.
- Настройки доступны кнопкой сверху или сочетанием Ctrl+,.

## Экспорт

Кнопка «Экспорт…» над графиком:

- **XLSX** — листы «Результаты» и «Параметры»: числа, единицы, магниты,
  датчик, параметры пути или исследования, дата и версия программы.
  Числа сохраняются без предварительного округления; недопустимые значения
  обозначаются текстом. Теория и отклонения добавляются только после
  «Сравнить с теорией».
- **PNG** — график в текущем масштабе с названием, осями и легендой.
  В визуализации также доступно изображение карты с текущими слоями.
  Подсказки курсора и рамки выбора объектов не экспортируются.

Экспорт результатов недоступен во время автоматического измерения.
Файл записывается через временный файл; при ошибке предыдущая версия сохраняется.
Замена существующего файла требует подтверждения в диалоге сохранения.

Результаты эксперимента нужно экспортировать **до закрытия программы**.
Автоматически сохраняются настройки и сцена визуализации; результаты измерений
и состояние исследования между запусками не восстанавливаются.

## Проверки

```bash
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
python -m pip check
```

Проверяются выбор и отмена пути, слои поля, устаревшие графики,
экспорт XLSX/PNG, восстановление настроек и основные сценарии измерений.
Тесты используют временные файлы и не изменяют пользовательские настройки.
